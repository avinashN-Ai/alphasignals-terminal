# 📈 AlphaSignals Pro - Stock Analysis & Buy/Sell Accuracy Platform
### (स्टॉक एनालिसिस और बाय/सेल एक्यूरेसी प्लेटफॉर्म)

A full-stack, institutional-grade stock analysis and algorithmic backtesting platform built for both Indian (NSE/BSE) and Global (US Tech) markets.

---

## 🌟 Key Features (मुख्य विशेषताएं)

1. **Multi-Indicator Confluence Signal Engine**:
   - Analyzes **EMA 20 / EMA 50 / EMA 200**, **RSI (14)**, **MACD (12, 26, 9)**, **Supertrend (10, 3)**, **Bollinger Bands (20, 2)**, and **Volume Confirmation**.
   - Generates unambiguous ratings: `STRONG BUY`, `BUY`, `NEUTRAL`, `SELL`, `STRONG SELL` with a **Confidence Score (0-100%)**.

2. **Algorithmic Accuracy & Win-Rate Engine (एक्यूरेसी कैसे देखें)**:
   - For every single stock, automatically backtests historical daily candles.
   - Measures exact **Win-Rate % (Accuracy)**, **Total Setups**, **Wins vs Losses**, **Profit Factor**, and **Max Drawdown**.
   - Filters out false signals using fresh crossover detection and adaptive ATR risk parameters.

3. **TradingView Lightweight Candlestick Charts**:
   - Interactive candlestick charts with volume bars, EMA 20 line (Cyan), EMA 50 line (Amber), and **Buy / Sell markers plotted directly on historical candles** with profit/loss outcomes!

4. **Interactive Strategy Backtest Simulator**:
   - Users can drag sliders for **Profit Target %** (1.5% - 15%), **Stop-Loss Limit** (1% - 8%), **Max Holding Days**, and **Min Confidence**.
   - Instant live re-calculation of Win-Rate and trade logs!
   - Toggle between **Equity / Cash (Buy Only)** and **F&O (Buy & Short)** modes.

5. **Trade Execution Plan**:
   - Provides recommended **Entry Price**, **Stop Loss**, **Target 1 (Conservative)**, and **Target 2 (Extended)** with calculated Risk-to-Reward ratio (e.g. 1:1.8).

6. **Hindi & English Quantitative Insights**:
   - Plain-language analysis explaining why the signal triggered and strict risk management rules.

## 🚀 How to Run the Website (साइट कैसे चलाएं)

### Option 1: Quick Run (Production Server on Port 5000)
Run this single command from the project root:
```bash
node server/server.js
```
Then open your browser and go to:
👉 **`http://localhost:5000`**

### Option 2: Full Development Mode (with Live Hot-Reloading)
```bash
npm run dev
```
- Frontend will open on: **`http://localhost:5173`**
- Backend API runs on: **`http://localhost:5000`**
